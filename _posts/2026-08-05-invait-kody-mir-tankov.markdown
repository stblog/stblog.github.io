<h2>Что такое инвайт-код в Мире танков</h2>
<p>Инвайт-код &mdash; это специальная комбинация букв и цифр, которую можно использовать для получения стартовых бонусов.</p>
<p>В отличие от обычного бонус-кода, инвайт-код предназначен для новых аккаунтов. По правилам Lesta его можно применить при создании учётной записи или в течение семи дней после регистрации.</p>
<p>Инвайт-код можно использовать только один раз для одной учётной записи.</p>

<h2>Можно ли активировать инвайт-код на старом аккаунте?</h2>
<p>Инвайт-код нельзя использовать на любом аккаунте в любое время.</p>
<p>Согласно правилам Lesta, он доступен при регистрации или в течение семи дней после создания учётной записи. Если с момента регистрации прошло больше семи дней, воспользоваться инвайт-кодом уже не получится.</p>
<p>Для существующих аккаунтов предназначены обычные бонус-коды. Их условия и сроки действия отличаются.</p>

<h2>Почему инвайт-код не работает?</h2>
<p>Если при регистрации появляется ошибка, проверьте несколько возможных причин:</p>
<ul>
	<li>
		<p><strong>Истёк срок действия.</strong> Некоторые коды распространяются только во время отдельных акций.</p>
	</li>
	<li>
		<p><strong>Превышен срок после регистрации.</strong> Инвайт-код можно использовать только при создании аккаунта или в течение семи дней после него.</p>
	</li>
	<li>
		<p><strong>Код введён с ошибкой.</strong> Проверьте последовательность букв и цифр.</p>
	</li>
	<li>
		<p><strong>Код уже использован.</strong> Один инвайт-код нельзя повторно применить к той же учётной записи.</p>
	</li>
	<li>
		<p><strong>Ограничения акции.</strong> У конкретного предложения могут быть дополнительные условия.</p>
	</li>
</ul>
